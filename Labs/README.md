## Mini Project

I built a simple Discretion AI launcher simulation.

The program:

1. Starts the Discretion AI application
2. Accepts a user's name and age
3. Uses conditional logic to classify the user
4. Displays available AI models
5. Allows the user to select a model
6. Stores model information in a dictionary
7. Checks the model's status
8. Simulates starting a local AI model
