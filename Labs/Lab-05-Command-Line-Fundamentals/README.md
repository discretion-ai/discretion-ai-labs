# Lab 05 – Command Line Fundamentals

## Objective

Practice basic command-line navigation, file creation, file management, and Git workflow using PowerShell inside Visual Studio Code.

## Commands Practiced

### pwd
Displays the current working directory.

### ls
Lists the files and folders in the current directory.

### cd
Changes the current working directory.

Example:
cd practice

### cd ..
Moves up one directory level.

### mkdir
Creates a new directory.

Example:
mkdir archive

### Get-Content
Displays the contents of a text file.

Example:
Get-Content command-line-practice.txt

### Git Commands

git status  
git add .  
git commit -m "Complete Lab 05 command line fundamentals"  
git push

## Lab Exercise

During this lab I:

1. Navigated through directories using PowerShell.
2. Created and viewed a text file.
3. Created an archive directory.
4. Moved the practice file into the archive directory.
5. Verified the file was moved successfully.
6. Used Git to stage, commit, and push the lab to GitHub.

## Key Takeaway

The command line provides a fast way to navigate directories, manage files, and interact with Git repositories. These skills will be important when working with Docker, Ollama, Python, AI applications, and development environments.
