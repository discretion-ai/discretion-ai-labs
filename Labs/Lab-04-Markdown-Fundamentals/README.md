Learn how to use Markdown to create professional documentation for Discretion AI Labs.

## Text Formatting

This is **bold text**.
This is *italic text*
This is 'inline code'.
The command 'git status' shows the current status of my Git repository.

## Skills Practiced

- Creating Markdown headings
- Formatting text
- Writing technical documentation
- Using Git with documentation

## Workflow

1. Create the file
2. Edit the documentation
3. Save the file
4. Stage the changes
5. Commit the changes
6. Push the changes to GitHub

## Command Example

The following commands show a basic Git workflow:

```bash
git status
git add .
git commit -m "Update documentation"
git push
```
