# Lab 02 - Git Fundamentals



\## Objective



Learn the fundamentals of Git version control and use Git to manage changes to the Discretion AI Labs repository.



\## Skills Practiced



\- Clone a remote repository

\- Check repository status

\- Create files locally

\- Stage changes

\- Commit changes

\- Push changes to GitHub



\## Commands Used



git clone

git status

git add

git commit

git push

git pull



\## Outcome



Completed the Git fundamentals lab and established a local development copy of the Discretion AI Labs repository.
